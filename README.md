# Paperkit

**PDF를 열고, 필요한 부분을 바로 고치는 데스크톱 편집기.**

Paperkit은 PDF의 텍스트, 이미지, 도형을 페이지 위에서 직접 편집하는 Windows 앱입니다. 문서를 서버에 업로드하지 않고 내 컴퓨터에서 작업하며, 편집 결과는 새 PDF로 저장합니다.

## 어떤 작업을 할 수 있나요?

- **여러 문서를 탭으로 작업** — PDF를 탭으로 열고 드래그해 순서를 바꿉니다. 로그인한 계정별로 탭 목록과 페이지·확대 상태를 복원합니다. 비로그인 작업은 앱 실행 중에만 유지합니다.
- **내 문서함** — 로그인 상태에서 열었던 PDF의 파일명과 위치를 모아 보고, 이름 검색과 즐겨찾기로 다시 찾습니다. 원본 PDF는 현재 컴퓨터에서 엽니다.
- **내 도구함** — 이미지·문구·워터마크·전자서명을 종류별로 모아 보고 보관합니다. 카드의 연필 버튼으로 이름과 내용을 수정합니다. 편집 화면에서 카드를 누르면 이미지·서명을 넣거나 문구를 복사하고 워터마크 설정을 엽니다.
- **본문에서 바로 수정** — 텍스트 블록을 더블 클릭해 내용을 입력하고, 글꼴과 정렬을 조정합니다.
- **이미지와 도형 배치** — 상단의 **이미지 삽입**으로 파일에서 가져오고, 가로·세로 핸들과 숫자로 크기를 조절합니다. Ctrl+C / Ctrl+V 또는 상단 **붙여넣기**로 PDF 객체와 외부 이미지를 붙여넣습니다.
- **워터마크** — 텍스트 또는 이미지 파일을 선택하고 투명도·크기·각도를 실시간 미리보기로 확인해 현재 페이지나 전체 페이지에 적용합니다. 문구 옆에 오늘 날짜를 붙일 수 있습니다. 생성한 워터마크는 위치가 고정되며, 워터마크 설정에서 교체·제거할 수 있습니다.
- **전자서명** — 마우스·터치·펜으로 그린 서명을 투명 이미지로 생성해 현재 페이지에 넣습니다. 기존 이미지처럼 이동·크기 조절·복사·삭제할 수 있습니다.
- **자유로운 텍스트 크기** — 상단 **상세**의 가로·세로 값으로 글자를 늘이고, 문단 핸들로 줄바꿈 폭을 조절합니다. 기존 줄 구분·들여쓰기를 유지하며 긴 내용은 원래 상자 높이를 넘어 확장됩니다.
- **문단 확장에 따른 배치** — 문단이 길어지면 같은 열의 아래 제목·목록·그림도 간격을 유지하며 내려갑니다. 입력 중 미리보기와 저장에 반영되며 한 번에 실행 취소할 수 있습니다. 이동한 내용이 페이지를 벗어나면 입력과 원본을 유지합니다.
- **입력에 맞춘 너비 자동 확장** — 여러 줄인 블록도 입력에 맞춰 가로로 늘어나고 페이지 오른쪽 끝에서 줄바꿈됩니다. 기존 줄 구분·들여쓰기를 유지합니다. 핸들로 줄바꿈 폭을 고정했어도 리본의 ‘너비 자동 확장’으로 되돌릴 수 있습니다.
- **원본 서식에 가깝게 편집** — 사용 가능한 PDF 내장 글꼴과 설치된 글꼴을 활용합니다. 글꼴 데이터나 문자가 부족한 경우에는 다른 글꼴을 선택할 수 있습니다.
- **편리한 문서 탐색** — 페이지 미리보기, 사이드바, 터치패드 두 손가락 핀치와 Ctrl + 마우스 휠 확대·축소를 지원합니다.
- **페이지 재방문 캐시** — 한 번 연 본문 페이지의 이미지와 편집 정보를 메모리에 보관해 다시 누르면 바로 표시합니다. 바뀐 페이지는 다시 준비하고, 문서를 닫으면 해당 캐시를 정리합니다. 캐시 용량을 넘으면 오래 보지 않은 페이지부터 비웁니다.
- **변경 사항 관리** — 실행 취소·다시 실행으로 작업을 되돌리고 새 파일로 저장합니다.
- **앱 업데이트 확인** — 앱 시작 시 새 릴리즈를 확인하고 i 버튼 아래 말풍선으로 알려줍니다. 알림에서 앱 정보 창을 열어 업데이트할 수 있습니다.

## 시작하기

1. [최신 릴리즈](https://github.com/NekoNyangYee/Paperkit/releases/latest)에서 Windows 설치 파일을 다운로드합니다.
2. Paperkit을 실행하고 PDF를 열거나 창에 끌어 놓습니다.
3. **편집 사용**을 누른 뒤 텍스트를 더블 클릭하거나 이미지·도형을 선택합니다.
4. 작업을 마치면 **새 PDF로 저장**합니다.

텍스트 입력은 **Enter**로 반영하고 **Shift + Enter**로 줄을 바꿉니다.

## 내 문서는 내 컴퓨터에

PDF 열기·편집·렌더링은 로컬에서 처리합니다. 버전 확인에는 GitHub API를 사용하며, 이때 PDF 내용은 전송하지 않습니다.

로그인 상태에서 연 문서의 파일명·경로·크기·최근 열람 시각과 즐겨찾기는 서버의 내 문서함에 기록합니다. 내 도구함에 직접 보관한 이미지와 문구도 서버에 저장합니다. 문서함 등록은 PDF 원본을 업로드하지 않습니다.

문서함·도구함과 로컬 탭 기록은 계정별로 분리합니다. 비로그인 상태에서는 문서 기록이나 열린 탭을 저장·복원하지 않으며, 로그인할 때 비로그인 문서를 계정에 자동 등록하지 않습니다. 직접 저장한 PDF는 선택한 위치에 남습니다.

## 알아두세요

PDF는 문서마다 내부 구조가 달라 편집 가능한 범위에 차이가 있습니다. 스캔 페이지는 로컬 OCR로 글자를 확인·복사할 수 있으며, 인식 결과는 확인이 필요합니다. 복합 객체는 하나의 묶음으로 처리합니다. 내장 글꼴에 없는 새 문자는 다른 글꼴을 직접 선택해야 할 수 있습니다. 일부 편집은 저장 결과 검증에서 변경이 제한될 수 있습니다.

## Paperkit이라는 이름

**Paper + Kit**, 문서를 다루는 도구 모음이라는 의미로 소개합니다. 종이 위의 내용을 손쉽게 고치고 정리하는 편집기를 지향합니다.
