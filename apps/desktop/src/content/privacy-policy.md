## Paperkit의 개인정보 처리

최종 수정일: 2026년 10월 16일 · 문서 버전 1.0

Paperkit은 사용자의 컴퓨터에서 PDF를 열고 편집하는 데스크톱 앱입니다. 이 안내는 현재 앱에서 처리하는 정보와 외부 연결을 설명합니다. 별도의 회원가입이나 개인정보 입력 없이 문서 편집 기능을 사용할 수 있습니다.

## 1. 문서 편집에 사용하는 정보

PDF를 열면 파일명, 파일 경로, 파일 크기, 문서 내용, 이미지, 글꼴 정보 등을 내 컴퓨터에서 처리합니다. 이 정보는 문서 표시, 편집, 실행 취소 및 저장에 사용됩니다.

**PDF 원본, 추출한 텍스트, 페이지 미리보기를 Paperkit 운영 서버에 업로드하지 않습니다.** 문서에 포함된 개인정보도 로컬 문서 처리 과정에서 사용되며, 원격 AI 분석에 전송하지 않습니다.

## 2. 저장과 보관

- 열린 문서와 편집 기록은 앱 실행 중 로컬 메모리에서 관리합니다. 문서 처리 상태는 문서 해제 또는 앱 종료 시 정리됩니다.
- 사용자가 저장한 PDF와 원본 파일은 사용자가 선택한 위치에 남습니다. 앱을 종료하거나 삭제해도 이 파일을 자동으로 삭제하지 않습니다.
- 업데이트 설치 파일은 앱의 로컬 캐시에 다운로드됩니다. 실패한 다운로드 임시 파일은 정리되지만, 설치를 위해 유지한 파일은 설치 후에도 남을 수 있습니다.
- 운영체제의 메모리 관리, 백업, 파일 동기화 프로그램이 보관하는 데이터는 해당 기능의 설정에 따라 관리됩니다. 앱 종료가 디스크의 모든 흔적에 대한 완전 삭제를 의미하지는 않습니다.

Paperkit은 문서의 서버 사본을 보관하지 않습니다. 저장한 문서를 삭제하려면 해당 파일과 사용 중인 백업·동기화 저장소를 직접 확인해 주세요.

## 3. 버전 확인과 외부 연결

앱의 버전 확인 창을 열거나 ‘최신 버전 확인’을 누르면 GitHub API에 공개 릴리즈 정보를 요청합니다. 업데이트를 선택하면 GitHub 및 다운로드 제공 경로에서 설치 파일과 검증 정보를 내려받습니다.

이 요청에 PDF 내용이나 파일 경로를 포함하지 않습니다. 다만 GitHub 등 연결 대상은 IP 주소, 요청 시각, 요청 주소, 클라이언트 정보 등 일반적인 접속 정보를 받을 수 있습니다. 해당 서비스가 처리하는 정보에는 그 서비스의 개인정보 처리방침이 적용됩니다.

GitHub 저장소나 릴리즈 설명의 외부 링크를 직접 누르면 외부 브라우저가 열립니다. 링크를 연 뒤의 정보 처리는 해당 사이트에서 이루어집니다. 버전 확인·다운로드를 사용하지 않아도 로컬 PDF 편집은 이용할 수 있습니다.

## 4. 추적과 오류 제보

현재 앱에는 광고, 행동 분석 추적기, 자동 오류 보고 전송 기능을 포함하지 않습니다. 이 개인정보 처리방침은 앱에 포함되어 있어 열람할 때 외부 페이지를 불러오지 않습니다.

사용자가 GitHub에 직접 문의하거나 오류를 제보하면 계정 정보와 작성한 내용은 GitHub에서 처리됩니다. 공개 이슈에 원본 문서, 비밀번호, 주민등록번호, 연락처 등 개인정보를 게시하지 마세요. 필요한 경우 개인정보를 제거한 예시와 오류 메시지만 공유해 주세요.

## 5. 정보의 제공과 사용자 선택

Paperkit은 로컬 편집 문서를 판매하거나 광고 목적으로 제공하지 않습니다. 사용자가 직접 저장·공유·외부 사이트에 첨부하는 행위는 앱의 자동 전송과 구분됩니다.

파일 열기를 취소하거나 문서를 닫아 해당 문서의 사용을 중단할 수 있습니다. 개인정보가 포함된 저장 파일은 직접 수정하거나 삭제할 수 있습니다. 외부 서비스에 직접 게시한 정보의 수정·삭제는 해당 서비스의 기능과 절차를 이용해 주세요.

## 6. 보호 조치와 안내 변경

앱은 원본과 별도의 PDF 저장, 변경 결과 검증, 업데이트 다운로드의 HTTPS 연결 및 무결성 확인을 사용합니다. 이러한 조치가 모든 문서 형식이나 운영체제 환경에서 위험을 완전히 없애는 것은 아닙니다.

이 안내는 현재 기능을 기준으로 작성되었습니다. 문서 업로드, 원격 분석, 계정 기능 등 정보 처리 방식이 변경되면 이 문서와 수정일을 갱신합니다. 보안 정책 문서에 적힌 향후 계획을 이미 제공되는 개인정보 보호 기능으로 설명하지 않습니다.
