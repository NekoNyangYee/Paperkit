# 프론트엔드 모달·미리보기·편집 화면

## 변경

- shadcn/ui의 Radix 기반 Alert Dialog / Dialog 구성 방식을 수동 설치하여 Paperkit 스타일로 적용했습니다. 구성 코드는 `src/components/ui`, 의존성은 pnpm으로 관리합니다.
- 저장하지 않은 변경 확인은 `useDiscardDialog`가 Promise로 응답합니다. 취소가 기본 포커스이며 Escape는 취소, 변경 버리기는 명시적 동작으로만 처리합니다. 앱 창 닫기와 문서 닫기에 같은 흐름을 사용합니다.
- 오류·작업 알림은 프론트 Alert Dialog로 표시합니다. 로딩 상태와 읽기 전용 안내는 작업 상태 표시로 유지합니다. 파일 선택·저장 위치 선택은 운영체제 파일 대화상자입니다.
- 모달 배경에 블러와 어두운 오버레이, 열기·닫기 애니메이션을 적용했습니다. 키보드 포커스와 Escape, 포커스 복귀는 Radix와 앱의 확인 훅으로 관리합니다. 모달이 열려 있을 때 편집 단축키를 실행하지 않습니다.
- 파일 선택 시 첫 페이지를 1600px 목표 폭으로 렌더링하고 이미지 디코딩을 마친 뒤 클릭을 허용합니다. 썸네일과 확대창이 동일한 이미지를 재사용하므로 클릭 후 저해상도에서 고해상도로 교체하거나 모달 크기가 바뀌지 않습니다. 준비 시간은 파일 선택 직후로 이동합니다.
- Lucide 아이콘으로 작업 버튼을 통일하고 `aria-label` 및 툴팁을 유지합니다. 페이지 썸네일과 번호, 캔버스 선택·크기 조절 핸들은 역할에 맞게 유지합니다.
- 페이지 사이드바가 전체 높이를 차지하며 헤더·툴바·문서는 오른쪽 열에 위치합니다. 접기/펴기는 고정 너비를 유지한 채 왼쪽 화면 밖으로 이동하는 전환을 사용하고 접힌 영역은 inert로 처리합니다. 기존 썸네일 캐시와 가상 스크롤을 유지합니다.
- 모달과 사이드바는 `prefers-reduced-motion`을 지원합니다.
