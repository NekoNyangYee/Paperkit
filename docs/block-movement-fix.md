# 자간이 있는 블록 이동 실패 수정

## 재현 및 원인

2026-10-10: `Tc`(자간), `Tw`(단어 간격), `TJ`(개별 글자 위치 보정)가 있는 PDF를 생성해 이동 실패를 재현했다. PDFium 객체 행렬을 이동하고 페이지 콘텐츠를 재생성하면 텍스트 폭이 123.186pt에서 104.436pt로 줄었다. 이동 검증이 이를 감지하고 변경을 취소했다. `reset_matrix` 대신 `translate`를 호출해도 동일했다.

사용자가 첨부한 보고서 PDF 자체는 저장소에 없으므로 해당 파일에서 동일 원인인지는 확인하지 못했다.

## 수정

- `lopdf = 0.45.0`의 콘텐츠 파서를 사용한다(default features 비활성화). [공식 API](https://docs.rs/lopdf/0.45.0/lopdf/struct.Document.html)를 확인했다.
- 원래 텍스트 출력 명령의 문자 코드, 글꼴 참조, 자간, 단어 간격, TJ 배열은 보존한다. 선택한 텍스트 출력 명령 전후에 서로 역인 평행이동 행렬을 추가한다.
- q/Q 및 cm으로 누적된 좌표계에서 이동량을 역변환한다. 회전된 페이지의 표시 좌표와 PDF 좌표 구분은 기존 로직을 유지한다.
- 공유 Contents 스트림을 수정하지 않고 선택 페이지에 새 콘텐츠 스트림을 연결한다.
- 엄격한 콘텐츠 파싱 및 64MiB 콘텐츠 디코딩 한도를 적용한다. 텍스트 명령과 PDFium 객체 개수가 다르면 매핑을 추측하지 않고 거부한다.
- 재열기 후 객체의 텍스트·글꼴·크기·색·변환 행렬·이동 경계, 비대상 객체, 이전/새 영역 밖 픽셀 검증을 유지한다. 원본 파일은 변경하지 않는다.

## 검증

- 수정 전 자간/TJ 사례에서 VerificationFailed 재현, 수정 후 통과.
- 소수점 행렬, 자간/단어 간격, 스케일된 좌표계, 작은따옴표/큰따옴표 텍스트 출력 명령 이동을 200% 렌더링으로 확인한다. 저장·재열기, Undo와 원본 바이트 보존을 검사한다.
- 기존 문단/열/표/회전/혼합 서식 이동 회귀 검사를 수행한다.
- 실제 사용자 보고서 및 Windows WebView에서의 육안 확인은 미수행이다.
