# 앱 내 업데이트

버전 조회는 기존 GitHub Releases API를 사용한다. 업데이트를 누르면 Rust가 고정 저장소의 해당 정식 태그에서 설치 파일과 SHA256SUMS.txt를 내려받는다. 브라우저나 임의의 프론트 URL·실행 경로는 설치에 사용하지 않는다.

- 현재 버전보다 높은 정식 SemVer만 허용한다.
- HTTPS, 연결·전체 타임아웃, 다운로드 용량 제한을 적용한다.
- 앱 캐시의 임시 파일에 저장하고 정확한 파일명의 SHA-256과 대조한다. 실패한 임시 파일은 제거한다.
- 검증된 파일만 Rust 상태에 보관하고 설치 직전 다시 검증한다.
- 프론트에 진행률을 전달하며 다운로드와 설치를 중복 실행하지 않는다.
- 편집기의 종료 확인을 거친 뒤 Tauri NSIS의 `/P /UPDATE /R` 옵션으로 설치·설정 보존·성공 후 재실행을 요청한다.

NSIS 옵션 근거: [Tauri 공식 설치 스크립트](https://github.com/tauri-apps/tauri/blob/dev/crates/tauri-bundler/src/bundle/windows/nsis/installer.nsi).

검증은 버전·파일명·체크섬 거부 테스트, 다운로드 진행률·재시도·재시작 취소 프론트 테스트와 실제 공개 설치 파일 다운로드 테스트를 포함한다. 실제 설치 파일을 실행하여 사용자의 설치를 덮어쓰는 테스트는 자동으로 수행하지 않는다. 체크섬은 GitHub의 동일 릴리즈에서 가져오며 별도 배포 서명 검증을 의미하지 않는다.

v0.1.0/v0.2.0은 기존 코드가 브라우저 다운로드 방식이므로 한 번 수동 설치해야 한다. 현재 설치 방식은 Windows x64 NSIS/currentUser 대상이다.
