# 블록 글꼴 변경 및 중앙 확대·축소

- 블록 글꼴 변경은 기존 줄 수/높이에 제한된 편집 경로 대신 flow 경로를 사용한다. 선택한 글꼴을 전체 스타일 run에 적용하며 크기와 색상은 보존한다.
- 기본은 기존 너비로 줄바꿈하고 높이는 내용에 따라 확장한다. 오른쪽 아래 핸들로 조절한 너비·높이와 입력 중인 내용을 글꼴 변경 명령에 함께 전달할 수 있다. 높이는 내용 잘라내기 제한이 아니며, PDF 페이지 경계 제한은 유지한다. 주변 블록을 자동으로 밀어내지는 않는다.
- 원본과 새 텍스트 영역의 합집합 바깥 픽셀, 비대상 객체, 저장·재열기 검증은 유지한다. 검증 실패를 무시하지 않는다.
- Ctrl+휠과 확대 비율 메뉴는 화면 중앙의 PDF 좌표를 기준으로 200ms 동안 문서 크기와 스크롤을 함께 갱신한다. 스크롤 끝에서는 브라우저의 경계 제한이 적용된다.
- 확대용 비트맵을 교체할 때 DOM을 재마운트하거나 별도 CSS 확대 애니메이션을 다시 시작하지 않는다. 새 이미지 디코딩 전까지 이전 비트맵을 유지한다.
- 한컴바탕은 설치 글꼴로 연결한다. 설치되지 않은 상용 글꼴 파일은 앱에 포함하지 않는다.

회귀 검사는 중앙 좌표 유지/비트맵 교체, 크기 조절 후 글꼴 변경 IPC, PDFium 긴 블록 글꼴 변경/높이 확장/Undo/저장·재열기/원본 보존을 포함한다. 사용자 스크린샷의 실제 PDF와 Windows WebView에서의 육안 확인은 수행하지 않았다.
