# 슬라이드 이동 미리보기 보완

사용자 화면에서는 드래그 중 페이지 전체가 검게 표시되고 이동 검증 실패가 함께 나타났다. 실제 `제19장+라우팅프로토콜 (1).pdf`는 저장소에 없어 동일 파일의 검은 화면은 재현하지 못했다.

- 이전 미리보기는 임시 문서에서 객체를 삭제하고 PDF 페이지 콘텐츠를 재생성했다. 이제 현재 열린 임시 페이지에서 비대상 객체를 `set_inactive()`로 숨기고 그 페이지 핸들로 직접 렌더링한다. 페이지를 다시 열거나 콘텐츠를 재생성하지 않는다.
- 투명 이동 레이어의 선택 영역 바깥에 불투명 픽셀이 생기면 표시하지 않고 미리보기 오류를 반환한다. 원본 페이지 화면은 유지한다.
- 이동 명령 실패를 프론트엔드까지 반환하여, busy 상태 변화가 생략되는 빠른 실패에서도 오프셋과 이동 레이어를 즉시 해제한다.
- 흰 배경/파란 헤더/빨간 글자 및 PDF Transparency 그룹이 있는 합성 PDF로 알파·배경색·텍스트색·원본 보존을 검사했다. 이동 거절 후 원본 비트맵 복원도 UI 회귀 검사한다.

이 변경은 이동 미리보기 보완이다. 화면에 함께 나타난 누락 글리프 오류나 해당 파일의 실제 이동 검증 실패가 모두 해결되었다고 확인한 것은 아니다.

## 후속: 표가 함께 움직이는 미리보기

비활성 플래그 대신 임시 문서에서 비대상 객체를 실제로 제거한다. Manual 모드에서 콘텐츠를 재생성하지 않고 동일한 열린 페이지 핸들로 렌더링한다. 표와 다른 텍스트가 겹친 합성 페이지에서 선택한 글자의 색상만 전경에 남는지 검사했다. 실제 참가확인서 PDF는 미제공 상태다.

첫 클릭 후 선택 오버레이가 생성되어 두 번째 클릭 대상이 달라지는 경로를 보완했다. 같은 객체와 근접 좌표에서 400ms 이내의 연속 클릭으로 편집에 진입한다. 글꼴 준비 상태와 원본 글꼴명 안내를 추가했다. 자동 다운로드와 시스템 글꼴 설치는 수행하지 않는다.
