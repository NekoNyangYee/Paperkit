# 커스텀 타이틀바와 비텍스트 객체 인식

타이틀바에 Paperkit 이름, 앱 버전·업데이트 확인, 최소화·최대화/복원·닫기를 배치한다. 창 장식 대신 Tauri 드래그 영역을 사용한다. 닫기는 `close()` 요청으로 기존 미저장 변경 확인을 거치며 `destroy()`를 직접 호출하지 않는다. 창 설정 변경은 앱 재시작 후 적용된다.

편집 사용 후 이미지와 도형을 페이지에서 직접 선택한다. 객체 안내 패널과 상시 경계 표시는 제거했다. 선택한 객체를 드래그하면 실제 내용이 움직이며 오른쪽 아래 핸들로 크기를 변경한다. 삭제 버튼 또는 Delete, 실행 취소·다시 실행, PDF 저장을 지원한다. 표와 큰 배경은 경계에서만 선택하여 내부 텍스트 클릭을 가로채지 않는다.

PDFium이 제공하는 페이지 최상위 객체를 사용하며 복합 객체 내부 요소는 하나의 복합 객체로 취급한다. 선·표 테두리도 벡터 경로이므로 포함된다. 별도 복사본에서 변환하고 다시 열어 대상 영역 밖과 다른 페이지의 픽셀 보존을 확인한 후 반영한다. 원본 파일은 덮어쓰지 않는다. 의미 기반 사물 인식, OCR, 그림 내부 글자 편집이나 이미지 교체는 포함하지 않는다.

검증: 창 제어 요청과 앱 정보 영역, 겹친 그래픽 선택을 프론트 테스트로 확인한다. 합성 PDF에 이미지·사각형·텍스트를 함께 배치해 유형 분리, 화면 좌표, 확대 시 객체 ID·PDF 좌표 유지, 원본 바이트 보존을 네이티브 회귀 테스트로 확인한다.

저장 시 이미지 객체를 소실하는 일부 인라인 이미지 형식은 검증 실패로 변경을 거부한다. 객체 개수와 변환 후 좌표도 확인하므로 이미지가 사라진 결과를 성공으로 반영하지 않는다. 일반 이미지 XObject와 벡터 사각형은 이동·크기 변경·삭제·실행 취소·다시 실행·저장 후 재열기를 검증한다. 실제 참가확인서의 도장 이미지도 배경 분리·이동·실행 취소를 확인했다.
