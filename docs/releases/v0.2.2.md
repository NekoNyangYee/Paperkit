# Paperkit v0.2.2

업데이트 버튼을 눌렀을 때 브라우저로 이동하던 흐름을 개선했습니다.

- 앱 안에서 새 버전을 다운로드하고 진행률을 확인할 수 있습니다.
- 다운로드가 끝나면 버튼이 **재시작하여 업데이트**로 바뀝니다. 원하는 시점에 누르면 새 버전을 설치하고 앱을 다시 엽니다.
- 저장하지 않은 작업이 있으면 재시작 전에 확인합니다. 취소하면 문서 작업을 계속할 수 있습니다.
- 다운로드한 파일을 확인한 뒤 설치하며, 다운로드가 끊기면 다시 시도할 수 있습니다.
- 변경된 Paperkit 저장소 주소에서도 최신 버전과 설치 파일을 올바르게 찾도록 수정했습니다.

**기존 버전 사용자 안내:** v0.1.0과 v0.2.0은 브라우저 다운로드 방식이므로 이번 버전은 설치 파일을 한 번 실행해 주세요. 이 버전부터 이후 업데이트에 앱 내 다운로드와 재시작 설치가 적용됩니다.
