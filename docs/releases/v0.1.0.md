# Paperkit v0.1.0 — 첫 공개 버전

Windows x64용 로컬 PDF 편집기입니다. 문서를 앱에서 열고 기존 텍스트를 수정한 뒤 새 PDF로 저장할 수 있습니다.

## 주요 기능

- 파일 선택 및 드래그 앤 드롭으로 PDF 열기, 파일 정보와 확대 미리보기 제공
- 원본 보호를 위한 기본 읽기 전용 모드와 편집 사용 전환
- 접을 수 있는 페이지 사이드바, 페이지 번호 이동, Ctrl + 마우스 휠 확대·축소
- 텍스트 블록 선택·이동·크기 조절, 여러 블록 선택과 임시 병합 편집
- 텍스트 더블 클릭으로 제자리 편집, Enter로 적용, Shift + Enter로 줄바꿈
- 글꼴 선택과 왼쪽·가운데·오른쪽·양쪽 정렬, 실행 취소·다시 실행
- 원본 글꼴 데이터의 지원 가능한 범위 내 재사용과 글꼴 매칭
- 원본을 덮어쓰지 않는 새 PDF 저장 및 저장 결과 재검증
- 최신 정식 릴리즈 자동 조회와 새 버전 설치 파일 다운로드 버튼

## 개선 및 배포 변경

- 텍스트 편집·이동 후 화면 갱신과 글꼴 검증 비용 개선
- 앱 내부 알림·확인 모달, 배경 흐림 효과와 사이드바 애니메이션 적용
- Windows CI의 Git 체크아웃 줄바꿈을 LF로 고정해 Prettier 검사 실패 수정
- 테스트·빌드 후 버전 태그로 설치 파일과 SHA256 체크섬을 게시하는 CI/CD 구성

## 설치 방법

1. 첨부된 `Paperkit_0.1.0_x64-setup.exe`를 다운로드해 실행하세요.
2. PDFium과 번들 글꼴·라이선스가 설치 파일에 포함됩니다.
3. 첨부된 `SHA256SUMS.txt`로 설치 파일의 무결성을 확인할 수 있습니다.

## 현재 제한 사항

- Windows x64만 지원하며 설치 파일은 코드 서명되지 않았습니다.
- PDF 구조와 내장 글꼴에 따라 일부 텍스트 편집이 제한될 수 있습니다. 부분 포함된 글꼴에 없는 문자는 동일한 전체 글꼴이나 대체 글꼴이 필요할 수 있습니다.
- 글꼴 변경·텍스트 추가 시 원본과 줄바꿈 또는 배치가 달라질 수 있습니다. 중요한 문서는 저장 결과를 확인해 주세요.
- OCR, 복잡한 문서 전체 재배치, 클라우드 동기화는 지원하지 않습니다.
- 업데이트 버튼은 설치 파일 다운로드를 엽니다. 다운로드 후 사용자가 설치 파일을 실행해야 합니다.
