# 버전 확인과 정렬

홈 화면과 편집기 헤더의 정보 아이콘으로 버전 창을 연다. 설치 버전은 Tauri의 `getVersion()`에서 읽는다. GitHub 공개 저장소의 `GET /repos/{owner}/{repo}/releases/latest`로 정식 릴리즈를 조회한다. 조회 실패·릴리즈 없음·제한 초과·시간 초과를 최신 버전으로 표시하지 않는다. 릴리즈 설명은 HTML로 실행하지 않는다.

창을 열면 `NekoNyangYee/pdf-editor`의 최신 릴리즈를 자동 조회한다. 저장소 입력은 제공하지 않는다. 설치 버전보다 최신이면 업데이트 버튼을 표시하며, 해당 릴리즈의 Windows x64 설치 파일을 기본 브라우저로 다운로드한다. 사용자가 받은 설치 파일을 실행해야 하며 앱 내부 자동 설치는 아니다. 설치 파일이 없는 릴리즈는 버튼을 비활성화하고 안내한다. 정식 릴리즈 게시 절차는 [CI/CD 안내](ci-release.md)를 참고한다.

편집 가능한 블록에서 왼쪽·가운데·오른쪽·양쪽 정렬 버튼을 사용한다. 입력 중에는 미리보기에 적용하고 Enter 또는 적용 버튼으로 저장한다. 입력하지 않는 상태에서는 선택한 블록에 바로 적용한다. 글꼴 변경과 함께 지정한 정렬도 반영한다.

PDF에는 문단 정렬 속성이 없는 경우가 많아 여러 줄의 공통 중심/오른쪽 끝을 비교해 자동 추정한다. 첫 줄 들여쓰기와 여러 줄 블록의 너비를 보존한다. 단일 줄 또는 모호한 배치는 자동 판별을 보장하지 않으며 수동 정렬을 선택할 수 있다. 양쪽 정렬은 공백 간격을 늘리고 마지막 줄과 명시적 줄바꿈 줄은 늘리지 않는다. 표·열이 다른 블록을 자동으로 합치지 않는다.

참고: [GitHub Releases API](https://docs.github.com/en/rest/releases/releases), [iLovePDF 기존 텍스트 편집 안내](https://www.ilovepdf.com/blog/edit-pdf-text). 동일한 정렬 조작을 제공하며 타사 내부 코드나 구현을 복제한 것은 아니다.
